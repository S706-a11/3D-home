# 3D Home - Three.js Project

Professional Three.js development environment with Vite, TypeScript, and Bun.

## Quick Start

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build
```

## Features

- ✨ Three.js 3D graphics engine
- ⚡ Vite for fast development and builds
- 📘 TypeScript for type safety
- 🚀 Bun for fast package management
- 🎮 Character movement system with WASD controls
- 📦 GLTF/GLB model loading with Draco compression
- 🎨 Professional scene with lighting and shadows

## Controls

- **WASD** or **Arrow Keys** - Move character
- **Mouse Drag** - Rotate camera
- **Mouse Scroll** - Zoom in/out
